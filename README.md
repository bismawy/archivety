# 🗂️ Archievty

Extract direct download links from Archive.org instantly. Get file URLs, metadata, security hashes (MD5, SHA1, CRC32), and export links in bulk—all in your browser, no login required.

## Features

- **Extract Direct Links** — Get download URLs from Archive.org items (supports `/details/`, `/download/`, `/embed/`, `/stream/`, or just the item ID)
- **Bulk Export** — Export all file links to `.txt` format for use with IDM or JDownloader
- **Search History** — Local browser history (localStorage) for quick access to recent extractions
- **Smooth Loading** — Skeleton loader animation during extraction
- **Dark/Light Mode** — Auto-switching theme with clean, minimal design
- **100% Client-Side** — All processing happens in your browser. No server, no data sent elsewhere. Safe and lightweight.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom variables, HSL colors (inspired by Tailwind/Shadcn)
- **JavaScript** — ES6+, Fetch API, AbortController, localStorage
- **Font** — Inter (via BunnyCDN)
